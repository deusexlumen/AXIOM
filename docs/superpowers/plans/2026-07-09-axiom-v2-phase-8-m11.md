# M11 Security + CI/CD + Deploy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** Implement milestone M11 of AXIOM v2.0: Supply-chain security (`axm audit`), controlled dependency addition (`axm deps add`), deployment (`axm deploy`), generated GitHub Actions workflow, and Headless-Heal CI job. Acceptance: all S-fixtures emit correct `AXM-Sxxx` codes; CI workflow is generated by `axm init`; Headless-Heal closes a prepared error autonomously in a PR.

**Architecture:** Security checks run as a dedicated `audit` stage before deploy. `axm deps add` is the only allowed path for new dependencies; it checks the DECISION_LEDGER for `forbidden-dependency` rules, pins the version, and updates `agent-context.json` integrity hashes. `axm deploy` sequences audit → full pipeline → migration dry-run → `pre-deploy` veto gate → Vercel deploy. The CI workflow is generated as a MACHINE file. Headless-Heal is an optional CI job that feeds FIX_PACKETs to a model endpoint and applies the returned patch as a PR commit.

**Tech Stack:** TypeScript 5.x, Zod 4 (`zod/v3`), Vitest 3, Node.js 22, pnpm 9, Vercel CLI.

## Task 2 — Audit Core

- [ ] Create `src/cli/security/audit.ts`.

```ts
import type { FixPacket } from "@/cli/schemas/fix-packet.js";

export interface AuditContext {
  cwd: string;
  packageJson: Record<string, unknown>;
  lockfileHash: string;
  manifestHash: string | null;
}

export async function runAudit(ctx: AuditContext): Promise<FixPacket[]> {
  const checks = [
    checkExactPinning,
    checkIgnoreScripts,
    checkLockfileIntegrity,
    checkAuditFindings,
  ];
  const out: FixPacket[] = [];
  for (const check of checks) {
    const packet = await check(ctx);
    if (packet) out.push(packet);
  }
  return out;
}
```

## Task 3 — `axm audit` Command

- [ ] Create `src/cli/commands/audit.ts`.

```ts
import { readFile } from "node:fs/promises";
import { resolve } from "node:path";
import { result } from "@/cli/utils/ndjson.js";
import { readContext } from "@/cli/manifest/mutate.js";
import { runAudit } from "@/cli/security/audit.js";
import { hashFile } from "@/cli/manifest/hash.js";
import { ExitCode } from "@/cli/types.js";
import { CliError } from "@/cli/errors.js";

export async function auditCommand(): Promise<void> {
  const cwd = process.cwd();
  const pkg = JSON.parse(await readFile(resolve(cwd, "package.json"), "utf-8")) as Record<string, unknown>;
  const lockfileHash = await hashFile(resolve(cwd, "pnpm-lock.yaml")).catch(() => "");
  const context = await readContext(cwd);
  const manifestHash = context.integrity.machineFiles["pnpm-lock.yaml"] ?? null;
  const packets = await runAudit({ cwd, packageJson: pkg, lockfileHash, manifestHash });
  if (packets.length > 0) {
    throw new CliError(JSON.stringify(packets[0]), ExitCode.SECURITY_ERROR);
  }
  result({ ok: true, violations: [] });
}
```

Run: `pnpm build` → OK.
