# M12 Visual Gate + AXIOM-Bench + Gesamtabnahme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** Implement milestone M12 of AXIOM v2.0: Visual Gate for deterministic pixel-diffing, AXIOM-Bench self-measurement, and end-to-end acceptance scenario S-12. Acceptance: Bench fixture M reports `GreenRate@1 ≥ 0.80`; S-12 runs a 12-component/6-endpoint vision through 4 workers and deploys to preview.

**Architecture:** Visual Gate is an opt-in pipeline stage. It runs only for components whose Sidecar has `"visual": true` and only when all four determinism pins are satisfied (locked Chromium, fixed viewport, local Inter font, disabled animations). Screenshots are compared with odiff; baseline updates require operator approval. AXIOM-Bench orchestrates the full Vision → DAG → Worker → Deploy flow against versioned fixture visions and writes an NDJSON report. S-12 ties both subsystems together.

**Tech Stack:** TypeScript 5.x, Playwright, odiff, Vitest 3, Node.js 22.

## Task 4 — Bench Runner + Metrics

- [ ] Create `src/cli/bench/runner.ts`.
  - Load fixture vision from `src/cli/fixtures/bench/<fixture>.json`.
  - Run `axm plan`, approve vision.
  - Dispatch simulated workers: loop `axm conduct --agents <n>`, claim orders, run `axm order complete`, collect results.
  - On failure, allow `axm heal --auto` up to `maxRetries`.
  - Track tokens from cost ledger.
- [ ] Create `src/cli/bench/metrics.ts`.
  - GreenRate@1 = DONE at first attempt / total orders.
  - medianTokensToGreen = median cost-ledger tokens for DONE orders.
  - MTTH = average fix cycles per order.
  - EscalationRate = BLOCKED / total.
  - SliceEfficiency = average slice tokens / order tokenBudget.
- [ ] Create `src/cli/bench/report.ts`.
  - Write `pipeline/bench/<runId>.ndjson` with metrics.

Run: `pnpm build` → OK.
